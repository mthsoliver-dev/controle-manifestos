# Controle de Manifestos

Sistema web para controle operacional de manifestos de transporte, emissão de NF e MTR, com acompanhamento de pendências e histórico de registros.

## Objetivo

Este projeto foi idealizado para auxiliar no acompanhamento diário de manifestos de transporte, reduzindo falhas operacionais e facilitando o controle de documentos obrigatórios.

## Funcionalidades

- Cadastro de manifestos por unidade
- Upload de imagens dos documentos
- Controle de NF
- Controle de MTR
- Marcação de NF não aplicável (N/A)
- Histórico de registros
- Filtros por data
- Filtros por unidade
- Indicadores de pendências e documentos concluídos
- Armazenamento local dos dados utilizando LocalStorage

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Como Utilizar

1. Selecione a unidade.
2. Adicione a imagem do documento.
3. Registre o manifesto.
4. Atualize os controles de NF e MTR.
5. Consulte o histórico utilizando os filtros disponíveis.

## Motivação

O projeto nasceu da necessidade de melhorar a organização e o acompanhamento dos manifestos de transporte utilizados nas operações logísticas do dia a dia.
